# POS Billingwala — Production UI Refresh

This package is a UI refresh of the supplied POS Billingwala website.

## Included
- 14 HTML screens from the supplied website
- Production UI override: `assets/css/site-production.css`
- Updated shared navigation in `assets/js/site-layout.js`
- Existing API/content JS retained
- Existing images/assets retained
- Responsive desktop/tablet/mobile styling
- Theme color and metadata polish

## Pages
Home, Software, Products, Pricing, Dealers, Support, Customers, Download, Contact, About, Company Model, Terms & Conditions, Privacy Policy, Refund & Renewal.

## Deployment
Upload the complete contents of this folder to the existing website document root. No build step is required.

Keep the existing Admin API endpoint/configuration unless you intentionally change your backend.
