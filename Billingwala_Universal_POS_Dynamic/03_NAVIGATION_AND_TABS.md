# Phase 3 - Dynamic Navigation and Tabs

Make Bottom Navigation, Drawer, Menus, Tabs, Sub Tabs, Quick Actions and Context Actions dynamic.

Create:
- NavigationConfiguration
- NavigationResolver
- TabRegistry
- TabConfiguration
- TabResolver
- TabGuard

Each item supports code, title, icon, module, feature, permission, visibility, order and badge.

Do not hardcode business-specific navigation.
