# Phase 7 - Restaurant, Bar and Mess

Restaurant:
Dine In, Take Away, Tables, Table Types, Merge, Transfer, Split Bill, Hold Bill, KOT and Kitchen Status.

KOT Settings:
Enable/Disable, Prefix, Preview, Printer, Copies.

Bar:
Bar Counter, Food, Beverage, Portions, ML, Bottle Conversion, BOT and separate printer routing.

Mess:
Common shop QR based on registration number.
Owner can Generate, Share and Print QR.
Customer scans using phone and does not install app.
Registered customer uses registration number.
Non-registered customer uses walk-in fast billing.
POS receives request and auto prints configured token.
