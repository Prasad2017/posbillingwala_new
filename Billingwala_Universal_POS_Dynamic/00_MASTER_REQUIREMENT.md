# Master Requirement

Make the entire Billingwala POS configuration driven.

Dynamic items include:
- Screens
- Navigation
- Tabs
- Dashboard
- Quick Actions
- Data and API mapping
- Forms and Fields
- Lists and Columns
- Search and Filters
- Validation
- Billing and Cart
- Payment and Workflow
- Shop Settings
- Printer Settings and Routing
- Invoice
- Reports
- Permissions
- Offline Data

Resolution:
Active Shop -> Business Template -> Modules -> Features -> Permissions -> Configuration -> Dynamic Data -> Dynamic UI

Supported businesses:
Restaurant, Cafe, Fast Food, Bar, Bar + Restaurant, Mess, Bakery, Cake Shop, Retail, Grocery, Wholesale, Fish, Meat, Chicken, Vegetable, Fruit, Clothing, Footwear, Salon, Beauty, Spa, Electronics, Mobile, Hardware, Repair, Rental and Custom Business.

Do not create separate business apps or duplicate engines.
