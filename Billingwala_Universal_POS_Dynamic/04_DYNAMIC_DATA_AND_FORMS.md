# Phase 4 - Dynamic Data and Forms

Do not only change labels. Actual data and fields must change.

Create:
- EntityConfiguration
- DataFieldResolver
- FormRegistry
- FormConfiguration
- FormSection
- FormField
- FieldValidator
- ListConfiguration
- ColumnConfiguration
- FilterConfiguration

Examples:
Restaurant: vegType, kitchenRoute, preparationTime
Bar: portion, ml, bottleSize
Fish: weightUnit, ratePerKg
Clothing: brand, size, color, variant
Electronics: serialNumber, warranty
Cake: weight, flavour, customOrder
Salon: duration, staff

Use structured fields for searchable and reporting data.
