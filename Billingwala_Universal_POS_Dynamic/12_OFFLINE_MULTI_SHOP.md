# Phase 12 - Offline and Multi-Shop

Cache per Shop:
Configuration, Modules, Features, Screens, Tabs, Forms, Fields, Products, Settings, Printers and Routing.

Cache key:
Business ID + Shop ID + Configuration Version.

Do not apply configuration while Cart, Payment or Printing is active.

Each shop may have different Business Type, Modules, Dashboard, Navigation, Tabs, Fields, Settings, Printers and Reports.

Never mix shop data.
Never delete historical data when modules are disabled.
Offline billing must continue.
